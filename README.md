# Orbe Premium — PWA

Aplicação web responsiva com suporte a instalação como app (PWA), modo claro/escuro, histórico, notas e Kanban.

## Publicação
Publique estes arquivos em GitHub Pages. O HTTPS do GitHub Pages permite a instalação do PWA em navegadores compatíveis.

## Instalação no celular
Abra a URL publicada. No Android/Chrome, use o botão **Instalar** quando aparecer ou o menu do navegador > **Instalar app**. No iPhone/iPad, use **Compartilhar > Adicionar à Tela de Início**.
